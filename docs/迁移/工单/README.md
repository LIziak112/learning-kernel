# 工单文件

每张工单一个文件：`工单/<工单号>.md`，工单号写成 `B<批次>-<短名>`，例如 `B4-judge-verdict`。只有主控写工单文件，写法是往文件末尾追加，不改已写的部分。本目录放的是派单、回执和复核的细节，台账只记结论和工单号。

## 派单（主控派出时写）

```text
工单：B<批次>-<短名>
覆盖 ID：<本批同一子组里的若干 ID，一单通常 3–10 个>
仓根／工作区／分支／基线 SHA：
允许写集：
数据副本：<路径；同一场景续用已有副本>
旧侧证据：<已有就引用位置，不重取>
待证行为与反例：
验收命令（L1）：<定向红测、绿测命令>
预算：墙钟 <N> 小时；本地全量 0 次（全量交给 CI）
交付：推到 <分支>，提交号
```

## 回执（SOL 交回后，主控原样贴，最多五行）

1. ID 与结论（待复核）
2. 提交号与远端分支；基线；`git diff --stat`
3. 关键红测及失败原因
4. 实际绿测命令、用例数；CI 链接（已推送的话）
5. 风险与未测

## 复核（主控写）

结论（通过、退回、阻断），依据（看了哪些文件、哪条 CI），回写台账的行。
