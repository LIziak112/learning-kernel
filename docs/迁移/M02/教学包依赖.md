# M02 教学包显式依赖旧侧实证

OwnClass 固定修订 `49a3fb0721c16cf9a2ba4f3d1f4fe89c471e3908`。内核记录基线为 `e7fec3e4e0131dedc1555b90cfe5b3acdbbf962a`。本次取证使用 Node 24.19.0 和 pnpm 12.6.0，通过 OwnClass 的 `createApp().request()` 进入真实路由。每例使用独立内存 SQLite、教师首设会话和临时媒体目录。MCP 通过真实 SDK 与教师 Bearer token 调用同一应用。

## 行为 ID 与实测结果

ID 来自 [M00 对外入口](../M00/对外入口.tsv#L395) 和 [M00 契约与内容](../M00/契约与内容.tsv#L255)。其中 `M02-P04` 使用已发布样例 `samples/lint/09-unknown-directive.md`，两类显式引用由该修订的 `packages/contract/src/teaching-pack.ts` 和 `packages/md-dsl/src/lint/teaching-pack.ts` 定义。

| 行为 ID | 旧侧入口 | 实际结果 |
| --- | --- | --- |
| `M02-import-preview` | 教师 `POST /api/teacher/import/preview`、`POST /api/teacher/import/preview-batch` | 两个预览均 HTTP 200。缺失的显式指令和校验器分别为 `DIRECTIVE_REF_NOT_FOUND`、`VALIDATOR_REF_NOT_FOUND`，级别均为 error。正文内同名未知指令单独报 `UNKNOWN_DIRECTIVE` warning。混合批次中只有坏文件 `hasError: true`。 |
| `M02-import-commit` | 教师 `POST /api/teacher/import/commit` | 先直接提交坏包，得到 HTTP 422 `LINT_ERROR`，`_issues` 含两条 error。讲义、练习、题目、资源文件夹、课程目录条目及导入留档六表与请求前一致。普通正文带 warning 导入成功，未知指令正文留在题干。改成合法声明重导后，讲义和练习各保存完整声明。再重导坏声明得到 422，六表既有行仍未变化。 |
| `M02-import-lint`、`M02-import-preview`、`M02-import-commit` | 教师 `/mcp` 的 `lint_markdown`、`import_markdown` | lint 与 dry-run 含同样两条 error 和一条 warning。确认提交返回 `isError: true`、`LINT_ERROR` 和两条 error，六表与请求前一致。 |
| `M02-import-zip` | 教师 `/mcp` 的 `import_zip` | 单份坏 Markdown 配一张图。预览返回依赖错误和图片配对，六表无变化且无媒体落盘。确认后报告中该文件为 `ok: false`、`LINT_ERROR`，六表仍无变化。图片独立上传，报告 `images.uploaded: 1`，按报告路径读取的文件与 ZIP 中原图逐字节一致。 |
| `M02-P04` | 固定样例 lint 和 `RichMarkdown` 渲染 | 样例中三个未知指令均为 warning，给出近似名建议。渲染选测确认未知容器、块和行内指令保留文字，容器回退还显示「未支持指令」标注。 |

依赖检查只解析 `teachingPack.directives` 和 `teachingPack.validators` 中列出的名字。已注册指令名及别名、题型能力表中的 `validatorId` 可通过。正例只声明了 `steps` 和 `judge`，正文使用的 `question` 未列出，仍能导入。

ZIP 以单份 Markdown 为内容提交事务边界，图片在逐文档提交前保存。固定修订的 `apps/server/src/services/zip-import-service.ts:519` 及 MCP 工具说明明确允许独立上传与部分失败。M02 沿用此口径，保留内容阻断与独立媒体上传。

## 复跑

在 P 固定修订仓根、安装锁定依赖后执行。将 `$m02KernelRepo` 设为本内核仓绝对路径。

```powershell
pnpm exec vitest run packages/md-dsl/src/lint/teaching-pack.test.ts apps/server/src/services/content-service.test.ts -t 'lintTeachingPack|教学包声明保存'
pnpm exec vitest run packages/md-dsl/src/lint/lint.test.ts apps/web/src/features/markdown/RichMarkdown.test.tsx -t '09 未注册指令|未知指令降级'
node --import ./apps/server/node_modules/tsx/dist/loader.mjs --test --test-isolation=none (Join-Path $m02KernelRepo 'docs/迁移/M02/teaching-pack-probe.mjs')
```

旧侧既有选测分别通过 12 例和 14 例，其余被名称过滤。新 [合成入口探针](teaching-pack-probe.mjs) 3 例全通过，覆盖路由返回、成功落库、坏重导及 ZIP 媒体实盘。首次探针将提交响应误当完整诊断列表，并把 MCP 预览诊断读作顶层字段。实测修正为提交错误仅含 error、MCP dry-run 诊断位于 `preview.issues`，ZIP 预览另有相对图源 warning。生产源码未改动，因此没有产品行为红测或修复提交。

本工单尚待教师浏览器、个人管理和个人 MCP 入口复验，以及新路径同夹具对照。教学包导出、共享导入、历史版本冻结和诊断复制各有对应验收项。
