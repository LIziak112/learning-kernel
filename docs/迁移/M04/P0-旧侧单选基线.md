## 候选与复跑

建卷时可从来源和冻结题声明筛掉非 `choice`、讲练、含材料或题组的候选，并以作业策略限制逐题反馈、限时、重做等额外行为。这些是候选范围，完整行为由后续工作包取证。参考产品 `apps/web/src/features/attempt/AttemptQuestionCard.tsx`，普通 choice 在 `ink` 生效时也挂载 `NoteLayer`。本次同卷 HTTP 探针证明创建时关闭期间仍可能恢复该能力，且关闭状态仍接受有效的草稿写入。真实作业暂无经实证可纳入的候选。AI 等独立的当前授权出口、草稿/标画本机状态与多标签同步均待对应工作包检验。

[冻结输入](P0-冻结单选.json)来自同卷已提交冻结题的教师授权投影，探针对其逐字段比对。P1 可直接复用题版本、稳定题标识、题面、选项、服务端答案键与三种答案向量。索引从 0 起，向量中的 `null` 表示该题无学生答案。运行生成的卷 ID、每卷题冻结行 ID、时间和哈希随实例而变，应由目标路径生成和核验。
