## 写法

- 只有当前主控写本文件。每次只改「在办」「待决」各一行，或「行为状态」里某个 ID 的整行；不写段落、不贴日志，单元格不超过两句。
- 派单、回执、复核的细节写进 `工单/<工单号>.md`（每单一个文件，格式见[工单说明](工单/README.md)），本表只引用工单号和证据位置。
- 只有收到 SOL 交付和主控复核结论这两个时点才改本表，派单时只在「在办」加一行，不必另记「待复核」。
- 改本表用整行替换。补丁对不上时，重读该行再替换；不写临时脚本修补，也不整份重写本文件。只有「恢复点」一节在每批收口时整节重写，限 15 行以内。
- 状态取值：`待验`、`历史待核`（旧台账里出现过，开工先按 ID 核对是否已有可复用证据）、`在办`、`待 CI`、`通过`、`阻断`。`通过` 必须写清两仓修订和证据位置。
