# 在学习平台内核使用 ub-mode

1. 从仓根读 `AGENTS.md` 和 `docs/学习平台内核首版实施清单.md`。按清单的“批次与停点”定位当前授权的一批，不把里程碑当作提交单位。环境准备工作保持全部产品任务的原有勾选状态。
2. 按 `AGENTS.md` 的“先让最小行为工作”“再整理实现”“按可验证的小步交付”执行。领域术语和职责查参考架构，首例行为查两步阅读实施规格。
3. 根据改动使用 README 列出的验收及质量工具。记录实际命令、用例数和失败原因，交接下一项。技能文件作为入口，项目规则以根目录 `AGENTS.md` 为准。
4. 派单、风险升级和整批审查遵循根规则的“按可验证的小步交付”；汇总时使用 PR 模板，不转述各子任务的过程日志。
